Nukera — анблочит **Instagram, Telegram, YouTube, Discord, Facebook, Whatsapp и все остальные** заблокированные сайты, даже те, которые другие варианты Zapret разблокировать не могут. Основано на Zapret и других принципах обхода, доработанных и заранее настроенных, в одном GUI приложении. Включил — сразу работает. 

Любая ОС: **Windows, MacOS, Linux и Android**, один репозиторий для всех платформ. Привычный итерфейс на всех устройствах. ВПН без ВПН. 

## Почему Nukera

- **Всё работает сразу — как с VPN**, но бесплатно и приватно. Без терминала, конфигов, ручной настройки.
- **Встроенный прокси для Telegram.** Приложение Telegram подключается через него автоматически — настраивать ничего не нужно. Тыкнуть на кнопку 1 раз, потом не нужно, только если что-то сломалось. Telegram Web работает сразу, без прокси. 
- **Instagram Reels, WhatsApp и Telegram** и другие — без доп настроек и конфигов.
- **Бесплатно, локально и приватно.** Всё на вашем компьютере, данные никуда не отправляются, это не VPN.
- **Открытый исходный код.** Ядро на Rust + GUI на Flutter.
- **Кросс-платформенно.** Windows, MacOS, Linux, Android — приложение работает на всех платформах из коробки.

## Установка — 30 секунд

- **Windows:** скачайте **`Nukera.exe`** и запустите.
- **Android:** установите **`Nukera-arm64-v8a.apk`** (разрешите установку из неизвестных источников и кликните **дополнительно** в процессе установки, чтобы установить приложение не подписанное из playmarket).
- **Linux:** запустите **`Nukera-Linux-x86_64.AppImage`** двойным кликом и примите **один** запрос пароля при первом запуске — дальше работает без запросов.
- **MacOS:** запустите **`Nukera-MacOS.dmg`** двойным кликом и в открывшемся окне клинкните на Install Nukera.command, чтобы установить Nukera в раздел приложений. После первого запуска примите **один** запрос пароля — дальше работает без запросов.

## 🛡️ Безопасность

«Защитник Windows» может пометить `Nukera.exe` как угрозу. **Это ложное срабатывание — приложение на 100 % безопасно.** Оно может тригеррить точно по тем же причинам, что и обычный Zapret.

Почему так выходит:
- **Приложение не подписано.** open-source приложение, и сертификат подписи с регистрацией в Microsoft Store получить долго и дорого. Windows по умолчанию относится к новым неподписанным файлам подозрительно.
- **Стек:** Windows-версия собрана на Flutter и упакована через PyInstaller и Inno Setup — инструменты, которые обеспечивают портативность приложения и отсутсвие необходимости устанавливать дополнительные библиотеки, эти инструменты тоже могут тригерить windows.  Антивирусные скрипты флагают даже безобидные программы с таким же набором.

Не переживайте:
- Вы можете проверить какие запросы делает приложение и понять что оно не меняет ваши файлы и не делает запросы на сторонние сайты. 
- Nukera **не собирает и не отправляет ваши данные никуда**. Она просто перенаправляет трафик, чтобы обойти блокировки, — всё остаётся на вашем устройстве.
- Я лично починю вам комп если что-то случится (не случится). 

## Инструкция

- **Все сайты разблокированы по умолчанию** — ничего не нужно настраивать дополнительно.
- **Telegram в браузере работает сразу**, из коробки.
- **Для приложения Telegram:** нажмите кнопку **«Настроить Телеграм»** — откроется Telegram, и вам останется принять прокси. Делается один раз, и связь работает, пока Nukera включён. Повторите, если прокси перестал работать.
- **Если какие-то сайты не работают:** нажмите кнопку **«Оптимизация» («Адаптировать под ваш интернет»)**. Запустится тест стратегий, и через несколько минут Nukera выберет лучшую для вашей сети. Делайте это только если реально не работает.
- **Android, страница не загружается:** обновите её 3–5 раз — загрузится и дальше будет открываться сразу. Проверьте, что приложение действительно включено; при необходимости сделайте force stop и перезапустите его.

Простая установка возможна только при условии релиза в AppStore. Если вы связанны с компанией, выпускающей приложения в AppStore, вы можете написать мне на почту finestcrtn@gmail.com

## Где может не работать
Linux версия:

- Нужен Linux с **systemd** и свежим glibc (≥ 2.39): Arch/Manjaro, Fedora ≥ 39 (вкл. Silverblue), Ubuntu 24.04 LTS, Debian 13, openSUSE Tumbleweed.
- На старых Ubuntu 22.04 / Debian 12 может не запуститься — будет показано предупреждение.
